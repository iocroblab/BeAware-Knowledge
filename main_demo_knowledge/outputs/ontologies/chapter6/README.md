# Chapter 6, (Re)Planning Design, Ontology Outputs

Reasoned and pre-reasoning ontology snapshots for the two PDDL Problem Generation scenarios (see `scenarios/chapter6/`).

- `ontology_before_reasoning_main_demo_baseline.xml` / `ontology_after_reasoning_main_demo_baseline.owl`: the Main Demo ontology in its baseline state, before and after reasoning, used to generate the baseline PDDL Problem.
- `ontology_before_reasoning_main_demo_extended.xml` / `ontology_after_reasoning_main_demo_extended.owl`: the Main Demo ontology with `ch06_pddl_gen_extended_scenario.yaml` layered on top, before and after reasoning, used to generate the extended PDDL Problem.
